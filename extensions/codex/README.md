# ACTAgent Codex

Official ACTAgent provider and harness plugin for OpenAI Codex app-server integration. It exposes the Codex-managed GPT model catalog and the Codex runtime surfaces used by ACTAgent agents.

Install from ACTAgent:

```bash
actagent plugin add @actagent/codex
```

Use this plugin when you want ACTAgent to run Codex-backed model turns, media understanding, and prompt overlays through the Codex app-server harness.
